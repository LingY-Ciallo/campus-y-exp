# 弯曲法测量杨氏模量（霍尔位置传感器）

用霍尔位置传感器测量梁在中部加载后的微小挠度，由挠度反算材料的杨氏模量。页面支持传感器定标拟合、梁尺寸多次测量取平均、挠度换算、结果明细与复制。

## 目录

```text
experiments/bending-modulus/
├─ README.md          本文件：参数、公式来源、输出与验算
└─ demo/              独立可运行的微信小程序

   ├─ pages/bending-modulus/   页面四件套 + calculator.js + 主题预览

   ├─ package.json
   └─ tests/                   计算与页面行为回归
```

## 运行

用微信开发者工具导入 `experiments/bending-modulus/demo/`，AppID 选测试号，不使用云服务。编译后点「载入示例」→「计算杨氏模量」。

测试：

```powershell
cd experiments/bending-modulus/demo
npm test
```

## 输入

| 名称 | 符号 | 单位 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| 定标点位置 | Z | mm | 是 | 4～12 个点，等间隔加砝码 |
| 定标点电压 | U | mV | 是 | 与 Z 一一对应，可为负 |
| 材料名 | — | — | 否 | 仅用于结果标注，默认「未命名材料」 |
| 梁厚度 | a | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 梁宽度 | b | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 刀口间距 | d | cm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 负荷 | M | g | 是 | 正数，默认 60 |
| 挠度位移 | ΔZ | mm | 二选一 | 直接填写的位移 |
| 挠度电压变化 | ΔU | mV | 二选一 | 只填 ΔU 时按 ΔU/K 换算 |
| 公认值 | Y_ref | Pa | 否 | 支持 `1.815e11` 这类写法 |

挠度组数可 1～6 组，同一次测量可重复加载同一负荷区间，结果取平均。

## 计算依据

1. **灵敏度 K**：对 U–Z 做最小二乘直线拟合，`K = |斜率|`，单位 V/m（U 用 mV、Z 用 mm 时数值换算正好为 V/m）。同时给出决定系数 R² 作为线性度参考。
2. **挠度**：`ΔZ = ΔU / K`。若直接填了 ΔZ，则跳过换算并按「直测」标注来源。
3. **杨氏模量**：弯曲法（中部单点加载、两支点简支）常用式

   ```text
   Y = d³ · M · g / (4 · a³ · b · ΔZ)
   ```

   其中 d 按 cm 输入、a 与 b 按 mm 输入、ΔZ 按 mm 输入，内部统一换算为 SI 后计算；`g = 9.8 m/s²`。
4. **相对误差**：填了公认值时为 `(Y − Y_ref) / Y_ref × 100%`，正负号保留，用于判断偏高还是偏低。

公式来源：本课程《霍尔位置传感器与弯曲法测量杨氏模量》实验指导书（实验 46）中的弯曲法测杨氏模量公式与霍尔传感器定标方法；常数 `g = 9.8 m/s²` 按指导书取值。

### 关于负荷 M 容易出错的一点

逐级加砝码时，每加一级得到的位移是**相邻两次读数之差**；若采用「加一级、减一级」的对消法，一组 ΔZ 对应的是**跨若干级的区间位移**。示例数据中每 60 g 给一个 ΔZ，因此 `M = 60 g`（`M·g = 0.588 N`），而不是单只砝码的 20 g。这一点填错会让结果正好差 3 倍，且不易察觉。

## 输出

| 输出 | 单位 | 精度 |
| --- | --- | --- |
| 灵敏度 K | V/m | 6 位有效数字 |
| 线性度 R² | — | 4 位小数 |
| 平均挠度 ΔZ | mm | 6 位有效数字 |
| 杨氏模量 Y | GPa | 2 位小数 |
| 杨氏模量 Y | Pa | 科学计数法 4 位小数 |
| 与公认值相比 | % | 2 位小数 |
| 挠度明细 | mm | 逐组列出，注明「直测」或「ΔU/K」 |

中间计算保留双精度，只在展示时舍入；「复制结果」输出文字版，含材料、K、R²、梁尺寸、负荷、平均挠度、Y 与挠度明细。

## 适用条件与未包含的内容

- 假设梁为等截面矩形、两支点简支、负荷作用于跨中，且挠度远小于跨长（小变形）。
- 只计算 A 类不确定度以外的量：**未包含**不确定度传递、B 类分量、仪器精度与扩展不确定度。若需要，请按指导书补公式后再扩展。
- 传感器定标假设 U–Z 在测量区间内线性；页面给出 R² 供判断，不自动剔除异常点。
- 不做单位换算提示：Z 用 mm、U 用 mV、a/b 用 mm、d 用 cm，按页面标注填写。
