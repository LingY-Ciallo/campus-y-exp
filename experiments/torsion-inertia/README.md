# 扭摆法测量转动惯量

用扭摆装置测量物体的摆动周期，由周期反算转动惯量。先用几何规则、理论值可算的圆柱体标定扭转常量 K，再求空载物盘的转动惯量 J0，最后求圆筒与细杆的转动惯量，并与各自的几何理论值比较。

## 输入

| 名称 | 符号 | 单位 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| 圆柱体质量 | m1 | g | 是 | 标定体，只测一次 |
| 圆柱体直径 | D1 | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 圆筒质量 | m2 | g | 是 | 只测一次 |
| 圆筒外径 | D外 | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 圆筒内径 | D内 | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 细杆质量 | m3 | g | 是 | 只测一次 |
| 细杆长度 | L | mm | 是（至少 1 个） | 三次测量，留空自动忽略 |
| 空载物盘周期 | T0 | s | 是（至少 1 个） | 三次测量取平均 |
| 放圆柱体后周期 | T1 | s | 是（至少 1 个） | 用于标定 |
| 放圆筒后周期 | T2 | s | 是（至少 1 个） | 用于求圆筒 |
| 放细杆后周期 | T3 | s | 是（至少 1 个） | 用于求细杆 |

质量、长度按实验记录的原始单位（g、mm）填写，周期按 s 填写，页面内部统一换算为国际单位。

## 计算依据

1. **几何理论值**（绕物体自身中心轴）：

   ```text
   实心圆柱体 J理 = m·D² / 8
   空心圆筒  J理 = m·(D外² + D内²) / 8
   细长杆    J理 = m·L² / 12
   ```

2. **扭转常量**：用圆柱体作标定体，圆柱体放入后周期由 T0 变为 T1，

   ```text
   K = 4π² · J1理 / (T1² − T0²)          （单位 N·m）
   ```

3. **空载物盘的转动惯量**：

   ```text
   J0 = (K / 4π²) · T0²
   ```

4. **待测物的实验值**：放入待测物后周期为 T，

   ```text
   J实 = (K / 4π²) · T² − J0
   ```

5. **相对误差**：`E = (J实 − J理) / J理 × 100%`，正负号保留，用于判断偏高还是偏低。

公式来源：本课程《扭摆法测量转动惯量》实验指导书（实验 3）中的扭摆法公式与周期测量方法；`π` 取双精度 `Math.PI`。

### 关于「圆柱体的误差恒为 0」

把 `K/4π² = J1理/(T1² − T0²)` 代回 `J实` 的式子，`T1²` 会恰好把分母约掉，得到 `J1实 ≡ J1理`。

所以圆柱体那行的 0.00% **不是测量得好，而是方法本身决定的**：它既是标定体，又出现在待测列表里，误差必然为零。判断本实验准确度要看圆筒与细杆的 E，不能看圆柱体。页面在表格下方也写了这一点。

### 关于 T1 必须大于 T0

放入圆柱体后转动惯量变大、周期变长，这是 `T1 > T0` 的物理依据，也是 K 的分母为正的前提。若两组周期填反，页面会直接报错，不会给出一个负的或发散的 K。

## 输入校验

- 质量、尺寸、周期逐项检查：空白格子忽略，填了就必须是大于 0 的数字；`0`、负数、非数字都会报错并指出是哪个量、第几次测量。
- 圆筒外径必须大于内径，否则报错（外径 ≤ 内径没有物理意义）。
- T1 必须大于 T0，否则报错并提示检查两组周期是否填反。
- T2 或 T3 小于 T0 时，算出的待测物转动惯量为负，页面报错而不是照常输出。
- 每个量至少填一次测量，全空会指出是哪个量缺数据。
- 载入示例前检查所有字段，只要有任何内容就先弹窗确认，避免覆盖已填数据。

## 输出

| 输出 | 单位 | 精度 |
| --- | --- | --- |
| 扭转常量 K | N·m | 6 位有效数字 |
| K / 4π² | kg·m²/s² | 科学计数法 4 位小数 |
| 空载物盘 J0 | kg·m² | 科学计数法 4 位小数 |
| 各物体 J理、J实 | kg·m² | 科学计数法 4 位小数 |
| 相对误差 E | % | 2 位小数 |
| 平均周期 T0～T3 | s | 6 位有效数字 |
| 测量次数 T0～T3 | 次 | 整数 |

中间计算保留双精度，只在展示时舍入。「复制结果」输出文字版，格式统一为**逐次读数 / 单位（均值，次数）**：质量、尺寸、周期都按这个写法逐行列出，填了几次就列几次（`100.1 / 100.2 / 100.2 mm（均值 100.167，3 次）`），不合并、不省略；随后是 K、K/4π²、J0，以及三项 J理 / J实 / E，末尾注明圆柱体 E = 0 由方法本身决定。

## 适用条件与未包含的内容

- 假设摆角很小（满足简谐近似）、待测物与载物盘同心放置、细杆绕中点垂直轴摆动。
- 只计算周期与几何量带来的结果：**未包含**不确定度传递、A/B 类分量、仪器精度与扩展不确定度。若需要，请按指导书补公式后再扩展。
- 不扣除空气阻尼与支架扭摆的影响；不自动剔除异常点（同一量的多次读数直接取算术平均）。
- 不做单位换算提示：质量用 g、尺寸用 mm、周期用 s，按页面标注填写。
